# java-racingcar-precourse

## 규칙 요약

- 자동차 이름은 ,(쉼표)로 구분하며 각 이름은 1~5자.
- 이동 횟수는 양의 정수.
- 매 라운드, 0~9 무작위 정수를 뽑아 4 이상이면 전진.
- 라운드 결과는 이름 : ---- 형식으로 출력(대시 개수 = 위치).
- 우승자는 최대 거리 기준 공동 우승 가능, ,로 구분하여 출력.
- 잘못된 입력 시 IllegalArgumentException 발생 후 애플리케이션 종료.

## 기능 목록

- [x] 입력 – 자동차 이름 문자열 파싱
    - [x] `,` 기준 split
    - [x] 각 토큰 공백 트리밍
    - [x] 이름 길이 5자 아래 검증
    - [x] 빈 이름/공백만/중복/연속 쉼표 등 유효성 검증

- [x] 입력 – 이동 횟수 파싱
    - [x] 숫자 형식 검증(정수)
    - [x] 1 이상 검증

- [x] 도메인 – `Car`
    - [x] 이름 보유, 위치(정수) 보유
    - [x] 전진 규칙: 랜덤 값 ≥ 4 → 위치 +1
    - [x] 출력 표현: `name : "----"` (대시 개수 = 위치)

- [x] 도메인 – `RacingGame`
    - [x] 라운드 수만큼 모든 자동차 전진 시도
    - [x] 라운드별 결과 순서대로 기록/출력
    - [x] 최종 우승자 계산(최대 위치 동점 허용)

- [x] 랜덤 정책 
    - [x] 기본 구현: 0~9 난수 생성

- [x] 출력 포맷
    - [x] “실행 결과” 헤더 출력
    - [x] 매 라운드 결과 출력(`이름 : ----`)
    - [x] 최종 우승자 출력: `최종 우승자 : name1,name2`

- [x] 예외 처리
    - [x] 입력 유효성 실패 시 `IllegalArgumentException` 즉시 발생
    - [x] 예외 발생 시 애플리케이션 종료

- [x] 설계 제약 준수
    - [x] indent depth ≤ 2 유지
    - [x] 3항 연산자 미사용
    - [x] 메서드 단일 책임 준수(파싱/검증/도메인/출력 분리)

- [x] 테스트
    - [x] 이름/이동횟수 입력 검증 테스트
    - [x] 전진 규칙 경계값 테스트
    - [x] 라운드 진행 및 누적 위치 테스트
    - [x] 우승자 단독/공동 케이스 테스트
    - [x] 예외 발생 케이스 테스트
